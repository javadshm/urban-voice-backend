# Urban Voice Frontend (Beginner Friendly)

This is a simple React frontend using React CDN (no build step).

## Pages

- **Landing Page** with QR code to submission page
- **Voice Submission Page** with login/register, language picker, voice recording, upload
- **User Dashboard** showing submission status, progress, and authority response

## Run locally

Open `frontend/index.html` in a browser, or run with Docker Compose from repository root.

## API URL

Default backend URL is `http://localhost:5000`.
